# AI Business Engine — Multi-Agent Workflow Experiments

A portfolio project exploring multi-agent AI workflows for two practical business problem areas:

1. Business acquisition research and due-diligence support.
2. Service and project estimating for contractors and local service businesses.

The repository README describes a CrewAI-based architecture using Python, Pydantic, LangChain, and OpenAI models. The current repository tree contains the README and an assets folder; the application source files described in the earlier README were not present in the accessible default-branch file tree when this review was performed.

For that reason, this project is presented as an **AI workflow concept / portfolio experiment**, not as a verified production system.

## Intended workflow areas

### Business acquisition research

The documented concept includes gathering business listing information, reviewing seller-provided financial information, identifying operational considerations, and producing a structured assessment.

### Contractor and service estimating

The documented concept includes collecting project requirements, organizing scope details, applying pricing assumptions, and preparing an estimate workflow.

## Technology described

- Python
- CrewAI
- Pydantic
- LangChain
- OpenAI models / GPT-4o

These technologies are listed in the project documentation; implementation and execution should be verified against source code before treating each component as completed.
